# スクリーンショットの置き方

READMEの先頭に4枚並べている。**画像ファイルは本人が置く。**

未ログインでは何も見えない設計なので、撮影にはログインした状態が要る。
パスワードを渡さずに済むよう、手順だけここに残しておく。

## 置き場所と中身

`docs/images/` に、この名前で置く。READMEはこの名前で参照している。

| ファイル | 画面 | 写っていてほしいもの |
|---|---|---|
| `home.png` | 本棚（`/`） | 次にやること、あなたの担当、新着の件数、表紙の並び |
| `unit.png` | 回の記録 | 種類の札、解決済みの疑問、返信スレッド、タグ |
| `book.png` | 教材の概要 | 複数行の目標、次にやる回、未解決の疑問の数 |
| `search.png` | 検索 | ハッシュタグ、種類での絞り込み、一致箇所の強調 |

## 撮るときの決めごと

**幅は1200px前後。** 狭いと折り返しが増え、広いと字が小さく写る。

**中身のある教材で撮る。** 記録が1〜2件しか無い回だと、何ができるアプリなのか
伝わらない。種類・タグ・返信・解決済みが一度に写る回を選ぶ。

**実際の輪講の中身が公開リポジトリに載る。** 他の参加者の書き込みが入るなら、
一言断るか、撮影用の教材を作ってそちらで撮る。

## 撮影用のデータを作る

実際に使っている教材には、種類を付けていない記録しか無いことがある。その状態だと
種類の札・解決済み・未解決の数がどれも写らない。撮影用に一式を作る道具を
その都度用意して、撮り終えたら消す（リポジトリには残さない）。

作るもの:

- 回を3つ（完了・進行中・未着手）。進捗バーが途中まで埋まる
- 予習メモ・疑問・復習を混ぜた記録。タグ付き
- 疑問は2つ。**片方を解決済みにして、片方は未解決のまま残す**
- 返信を2件付けてスレッドにする
