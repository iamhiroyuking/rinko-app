# rinko-app

輪講（ゼミ・研究室の輪講/reading group）の運営を楽にするアプリ。

## 背景・課題
研究室の輪講で、進捗が曖昧になる／全体像が見えない／演習の実施記録が残らない／担当者の予習に見合う進度が出ない、といった課題があった。詳細は [docs/requirements.md](docs/requirements.md) を参照。

## 解決したいこと（MVP）
輪講の進度を一覧でパッと見えるようにし、目標ペースとの差分を可視化する。各回に担当者・目的・演習メモを残せるようにして、後から全員が振り返れるようにする。詳細な機能一覧・データモデルは [docs/requirements.md](docs/requirements.md) を参照。
